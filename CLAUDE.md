# CLAUDE.md

## Project

A static, responsive hello-world single page application published on GitHub Pages.
Plain HTML/CSS/JS with no build step: `index.html`, `style.css`, `app.js` (hash-based router).

## Workflow

- Never commit directly to `main`. Do all work on a feature branch.
- When changes are done, commit, push the branch, and open a pull request against `main`
  so the owner can review and approve it before merging.
- Do not merge pull requests yourself.
